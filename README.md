"# 3D Interactive Portfolio Website

A modern portfolio website built with React 19, Three.js, and Tailwind CSS v4 featuring an interactive 3D navigation cube.

![React](https://img.shields.io/badge/React-19-61DAFB?style=for-the-badge&logo=react)
![Three.js](https://img.shields.io/badge/Three.js-0.181-000000?style=for-the-badge&logo=three.js)
![Tailwind](https://img.shields.io/badge/Tailwind-v4-38B2AC?style=for-the-badge&logo=tailwind-css)

## Features

- **Interactive 3D Cube** - Rotating geometric hub with clickable faces for navigation
- **Modern Dark Theme** - Sleek design with cyan/purple accents
- **Smooth Animations** - Powered by Framer Motion
- **Fully Responsive** - Works on all devices
- **CSS Marquee Skills** - GPU-accelerated skill badges carousel

## Quick Start

### Development

```bash
npm install
npm run dev
```

Visit http://localhost:5173 to see your portfolio.

## Customize Your Portfolio

Edit the data files in `src/data/`:

- `src/data/portfolioData.js` — All content (personal info, skills, projects, contact)

## Tech Stack

- React 19
- Three.js & React Three Fiber / Drei
- Framer Motion
- Tailwind CSS v4
- Lucide Icons

## Deploy

### Production Build

```bash
npm run build
```

### Deploy To:

- **Vercel** (Recommended): `npx vercel`
- **Netlify**: Connect your repo

## Color Theme

- Background: `#0a0a0f`, `#12121a`
- Accent Cyan: `#00d9ff`, `#0ea5e9`
- Accent Purple: `#8b5cf6`, `#a78bfa`

## Environment Variables

Copy `.env.example` to `.env` and fill in your EmailJS credentials for the contact form to work.
